# 工作流细则

## 直接生成

用户选择 `1` 后提示：

```text
请把你的原始内容发给我。

可以是语音转文字、零散想法、中文草稿，或比较完整的中文口播稿，不需要提前整理。
```

收到内容后：

1. 提取核心主题、主要观点、关键经历和希望观众记住的内容。
2. 删除无意义语气词、转写噪声和明显重复。
3. 合并同义内容，调整顺序，补上不引入新事实的必要衔接。
4. 若存在会实质改变成稿的关键信息缺口，只问一个最重要的问题；否则直接进入难度选择。
5. 用户选择难度后生成成稿。

## 问答生成

用户选择 `2` 后提示：

```text
先告诉我你想聊什么。

可以只给一个主题、一个观点、一件最近发生的事、一段经历，或者一句话。
```

根据用户已经提供的信息动态追问，不使用固定问卷。每轮原则上只问一个核心问题；只有两个问题高度相关、分开询问会明显打断对话时，才在同一轮问两个。

可按需探索：背景与起因、具体经过、人物和场景、感受与想法、转折、前后变化、采取的行动、结果、意外或冲突、最深刻的细节、现在的看法、希望观众记住什么、是否想给建议。

优先问能增加真实细节或决定叙事方向的问题。不要重复询问已知信息，不要为了凑轮数而继续追问。通常在内容足以形成完整口播后，简短概括已收集到的主线并询问是否生成；用户也可以随时用控制指令结束问答。

## 问答控制指令

在问答开始时简短告知，用户可以输入：

- `生成`：停止追问，用现有信息进入难度选择并生成。
- `继续问`：继续补充内容。
- `跳过`：跳过当前问题，换一个更有价值的方向；若已足够则建议生成。
- `返回`：回到上一轮，允许更正上一条回答。
- `重来`：清空本轮已收集内容，重新选择主题；执行前先确认一次，避免误触。
- `退出`：结束本次创作，不再追问。

自然语言表达与这些指令含义一致时同样生效，不强迫用户输入固定格式。

## 难度选择

在信息整理完成、正式生成前显示：

```text
请选择英文难度：

1｜简单自然
短句和高频词为主，容易理解、记忆和开口。

2｜自然进阶（推荐）
表达更丰富，但仍像真实 Vlog 口语。

3｜高级自然
词汇和句式更有层次，但不书面化、不故意炫技。

请回复 1、2 或 3。也可以直接说“按我的英文水平来”。
```

若用户已明确英文水平、目标难度或风格，则据此生成，不再重复询问。选择“按我的英文水平来”但没有可用线索时，采用 `2｜自然进阶`，并说明可以随时调简单。

难度只影响词汇、句式复杂度和表达精细度，不改变事实、立场或内容主线。

## 成稿组织

根据内容自然组织，不强套模板。通常包含：

1. 能迅速进入主题的自然开场。
2. 按因果、时间或观点关系展开的主体。
3. 清楚的转折或关键认识（如果素材中存在）。
4. 简洁、像真人说话的收尾。

不要凭空制造“爆款钩子”、戏剧冲突或人生感悟。除非用户要求，不附逐句中文翻译、词汇表、音标、标题或拍摄建议。

## 二次修改

每次交付成稿后显示：

```text
接下来你可以回复编号继续修改：

1｜更简单、更好说
2｜更自然、更像真人口语
3｜更高级，但保持口语感
4｜缩短内容
5｜扩展内容
6｜调整语气或风格
7｜修改指定段落或句子
8｜提供中英对照
9｜重新生成一版
0｜完成
```

执行修改时只改变用户指定的维度，保留其他已经满意的内容：

- `4` 或 `5` 若用户未给目标长度，先按约 20%–30% 调整，不机械增删观点。
- `6` 只在具体风格会显著影响结果而用户未说明时，追问一个简短问题。
- `7` 请用户贴出或指出目标位置及修改意图。
- `8` 按段落提供英文与自然中文释义，不把英文倒改成直译腔。
- `9` 保留相同事实、立场和难度，换一种自然组织和表达。
- `0` 简短结束，不继续推销其他功能。

用户也可以直接用自然语言提出修改，不必使用菜单编号。
