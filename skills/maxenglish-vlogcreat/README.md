# maxenglish-vlogcreat

`maxenglish-vlogcreat` 是一个面向英文 Vlog 和英文口播创作的 Codex Skill。它会先理解并整理中文主题、零散想法、语音转写或草稿，再写成自然、真实、可以直接对镜头说的英文，而不是逐句翻译。

## 启动方式

在 Codex 中输入：

```text
$maxenglish-vlogcreat
```

也可以直接带上需求，例如：

```text
$maxenglish-vlogcreat 帮我把这段中文整理成英文口播稿
```

## 两种生成模式

### 1｜直接生成

适合已经有语音转文字、零散想法、中文草稿或较完整内容。Skill 会先去掉噪声和重复，调整逻辑与衔接，再根据所选难度生成英文成稿。

### 2｜问答生成

适合只有一个主题或大概想法。Skill 会像聊天一样动态追问，每轮通常只问一个最有价值的问题；信息足够后再生成，不使用固定问卷。

## 难度选择

- `1｜简单自然`：短句和高频词为主，容易记、容易说。
- `2｜自然进阶（推荐）`：表达更丰富，同时保持真实口语感。
- `3｜高级自然`：词汇和句式更有层次，但不写成书面文章。

难度只影响英文表达，不改变原意。无论选择哪一级，都以自然、常用、适合口播为前提。

## 问答控制指令

- `生成`：使用现有信息开始生成。
- `继续问`：继续补充内容。
- `跳过`：跳过当前问题。
- `返回`：更正上一轮回答。
- `重来`：确认后清空本轮内容并重新开始。
- `退出`：结束本次创作。

也可以用意思相同的自然语言，不必死记指令。

## 二次修改菜单

成稿后可继续选择：

1. 更简单、更好说
2. 更自然、更像真人口语
3. 更高级，但保持口语感
4. 缩短内容
5. 扩展内容
6. 调整语气或风格
7. 修改指定段落或句子
8. 提供中英对照
9. 重新生成一版
0. 完成

## 设计原则

- 先理解、再重组、最后英文表达。
- 可以删除废话、合并重复、调整顺序和补充必要衔接。
- 不编造个人经历、数据、案例、人物或冲突。
- 不改变用户立场，不把温和观点改成极端观点。
- 难度提升不等于书面程度提升。

## 维护建议

优先根据真实使用反馈做小幅、可验证的调整。若新增模式或输出格式，应放入独立参考文件并从 `SKILL.md` 明确链接，避免入口文件持续膨胀。不要把一次性的个人偏好升级为所有用户都必须遵守的固定规则。
