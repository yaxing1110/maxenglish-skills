# 工作流细则

## 直接生成

用户选择 `1` 后提示：

```text
请把你的原始内容发给我。

可以是语音转文字、零散想法、中文草稿，或比较完整的中文内容，不需要提前整理。
```

收到内容后：

1. 提取用户真正想练习表达的主题、观点、经历和感受。
2. 删除无意义语气词、转写噪声和明显重复。
3. 合并同义内容，调整顺序，补上不引入新事实的必要衔接。
4. 若存在会实质改变稿件的关键信息缺口，只问一个最重要的问题；否则进入难度选择。
5. 用户选择难度后生成英语口语练习稿。

## 问答生成

用户选择 `2` 后提示：

```text
先告诉我你想练习用英语聊什么。

可以只给一个主题、一个观点、一件最近发生的事、一段经历，或者一句话。
```

根据用户已经提供的信息动态追问，不使用固定问卷。每轮原则上只问一个核心问题；只有两个问题高度相关、分开询问会明显打断对话时，才同时问两个。

可按需探索：背景与起因、具体经过、人物和场景、感受与想法、转折、前后变化、采取的行动、结果、印象深刻的细节、现在的看法、最想练会表达的内容。

追问是为了获得真实、可供用户练习的个人表达，不是为了制造故事冲突、吸引观众或提高传播效果。不要询问目标平台、受众、拍摄方式或发布计划。

信息足以形成完整独白后，简短概括主线并询问是否生成。用户也可以随时使用控制指令。

## 问答控制指令

- `生成`：停止追问，用现有信息进入难度选择并生成。
- `继续问`：继续补充内容。
- `跳过`：跳过当前问题，换一个更有价值的方向；若信息已足够则建议生成。
- `返回`：回到上一轮，允许更正上一条回答。
- `重来`：清空本轮已收集内容，重新选择主题；执行前先确认一次。
- `退出`：结束本次练习稿创作，不再追问。

意思相同的自然语言同样生效，不强迫用户输入固定格式。

## 难度选择

在正式生成前显示：

```text
请选择英文难度：

1｜简单自然
短句和高频词为主，容易理解、记忆和开口。

2｜自然进阶（推荐）
表达更丰富，但仍然自然、生活化、容易说出口。

3｜高级自然
词汇和句式更有层次，但不书面化、不故意炫技。

请回复 1、2 或 3。也可以直接说“按我的英文水平来”。
```

若用户已明确英语水平或目标难度，不重复询问。选择“按我的英文水平来”但没有可用线索时，采用 `2｜自然进阶`，并说明可以随时调简单。

难度只影响词汇、句式复杂度和表达精细度，不改变事实、立场或内容主线。

## 成稿组织

根据内容的自然逻辑组织，不强套固定结构。通常包括自然进入主题、展开经历或观点、说清变化或认识，以及自然结束。

稿件服务于开口练习：

- 使用适合连续朗读的句长和节奏。
- 优先选择用户真正可能说出口的表达。
- 允许自然的口语连接，但不要堆砌填充词。
- 不写标题、封面文案、视频开场钩子、观众互动、关注引导或平台文案。
- 除非用户要求，不默认附中文翻译、词汇表、音标或练习标记。

## 二次修改

每次交付成稿后显示：

```text
接下来你可以回复编号继续修改：

1｜更简单、更好说
2｜更自然、更像真人口语
3｜更高级，但保持口语感
4｜缩短内容
5｜扩展内容
6｜调整语气或风格
7｜修改指定段落或句子
8｜提供中英对照
9｜生成口语练习标注版
10｜重新生成一版
0｜完成
```

执行修改时只改变用户指定的维度，保留其他已经满意的内容：

- `4` 或 `5` 若用户未给目标长度，先按约 20%–30% 调整，不机械增删观点。
- `6` 只在风格会显著影响结果且用户未说明时，追问一个简短问题。
- `7` 请用户贴出或指出目标位置及修改意图。
- `8` 按段落提供英文与自然中文释义，不把英文倒改成直译腔。
- `9` 在不改写原文的前提下标注自然停顿、意群和建议重读词，方便跟读与复述。
- `10` 保留相同事实、立场和难度，换一种自然表达。
- `0` 简短结束。

用户也可以直接用自然语言提出修改，不必使用菜单编号。
