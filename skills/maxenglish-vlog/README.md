# maxenglish-vlog

`maxenglish-vlog` 用来把中文主题、零散想法、语音转写或草稿整理成自然、生活化、适合朗读和跟读的英文口语练习稿。

它不是视频策划工具，也不假设用户要发布内容。这里的 “Vlog 风格” 只表示第一人称、像真人分享生活和想法的自然口语感。用户可以对着空气、镜子或录音设备练习，完全不需要拍摄或发布。

## 启动方式

```text
$maxenglish-vlog
```

也可以直接附上内容：

```text
$maxenglish-vlog 帮我把这段中文整理成适合口语练习的英文稿
```

## 两种模式

### 1｜直接生成

适合已经有语音转文字、零散想法、中文草稿或较完整内容。Skill 会先整理信息，再根据所选难度生成英文练习稿。

### 2｜问答生成

适合只有一个主题或大概想法。Skill 会像聊天一样动态追问，帮助用户补充真实经历和想法；问题服务于个人表达练习，不服务于视频传播。

## 明确不做什么

除非用户明确要求，否则不会提供：

- 小红书、抖音、Bilibili、YouTube 等平台策划
- 爆款标题、视频钩子、封面文案或行动引导
- 镜头、拍摄、剪辑、字幕或发布建议
- 受众定位、流量优化或营销文案

## 英文难度

- `1｜简单自然`：短句和高频词为主，容易记、容易说。
- `2｜自然进阶（推荐）`：表达更丰富，同时保持生活化口语感。
- `3｜高级自然`：词汇和句式更有层次，但不写成书面文章。

## 问答控制指令

- `生成`：使用现有信息开始生成。
- `继续问`：继续补充内容。
- `跳过`：跳过当前问题。
- `返回`：更正上一轮回答。
- `重来`：确认后清空本轮内容并重新开始。
- `退出`：结束本次练习稿创作。

## 二次修改

成稿后可以继续简化、自然化、提升难度、缩短、扩展、修改指定段落、生成中英对照，或生成带自然停顿、意群和重读提示的口语练习标注版。

## 设计原则

- 先理解、再重组、最后用自然英文表达。
- 可以删除废话、合并重复、调整顺序和补充必要衔接。
- 不编造个人经历、数据、人物或冲突。
- 不改变用户立场。
- 以容易开口、自然朗读和真实表达为最终标准。
