# maxenglish-vlog

`maxenglish-vlog` 把主题、模糊想法、语音转写或中文草稿先整理、重组，再转换成自然、真实、适合开口练习的英文 Vlog / 英文口播稿。

它不是逐句翻译工具，也不是视频运营或社交媒体策划工具。用户可以直接拿生成结果练习、朗读或复述，也可以自行决定是否录音、录制；Skill 不会默认用户要发布视频。

## 启动

在支持 Skill 的界面中调用：

```text
@maxenglish-vlog
```

在使用 `$` 调用的环境中也可以输入：

```text
$maxenglish-vlog
```

无附加内容时固定进入模式选择：

1. 直接生成：适合已有想法、转写或中文草稿。
2. 问答生成：适合只有主题，通过动态追问补充真实经历和细节。

## 问答规则

- 每轮原则上只问一个核心问题，必要时最多两个高度相关的问题。
- 默认约 3—6 轮有效追问，但不凑轮数。
- 用户可随时回复 `结束问答`、`跳过` 或 `重新开始`。
- 追问的目标是取得用户真实经历、观点和细节，不能替用户编造人生经历。

## 难度

- `1｜简单`：约 100—160 词，高频词、短句、容易开口。
- `2｜中等`：约 160—250 词，允许常用搭配、phrasal verbs 和自然从句。
- `3｜较难`：表达更深入、成熟、地道，但仍然是口语，不写成正式文章。

长度是建议范围，始终以内容质量为先。

## 输出

生成前会在内部检查自然度、翻译腔、书面表达、句长、逻辑、语法、难度、个人风格、事实边界和 AI 模板感。最终只输出检查后的稿件：

```text
## English Script

正文……

Word count: 213
```

## 生成后的操作

1. 更简单
2. 同难度重写
3. 更自然、更像真人说话
4. 缩短
5. 扩写
6. 重新选择难度
7. 更像生活 Vlog
8. 更像观点型口播

## 核心边界

- 可以重组，但不能篡改。
- 不编造经历、数据、案例、名人观点或虚假冲突。
- 不改变用户立场，不把温和观点改成极端观点。
- 难度提升不等于书面程度提升。
- 不主动提供小红书、短视频平台、标题、封面、钩子、分镜、流量或营销建议。
