# maxenglish-vlog

帮助用户把自己真正想说的内容整理成英文独白，用于个人英语口语练习。用户可以对着空气、镜子、录音设备或镜头练习，也可以完全不拍摄、不发布。

这里的 “Vlog 风格” 仅指自然、生活化、第一人称、像真人分享经历和想法的表达方式，不代表视频创作任务。

## 启动

如果用户只调用 `$maxenglish-vlog`、尚未选择模式，也没有附加内容，回复必须只显示下面的菜单；菜单前后不能添加任何说明，不要解释能力，不要列举示例，不要改成开放式“需求模式”。

```text
请选择生成方式：

1｜直接生成
适合已经有想法、语音转文字、草稿或完整中文内容。

2｜问答生成
适合只有一个主题或大概想法，通过几轮问答补充内容后再生成。

请回复 1 或 2。
```

若用户在调用时已经明确选择模式或提供了足够内容，不重复询问已知信息。

## 核心边界

- 目标是生成供用户朗读、跟读、复述和练习开口的英文稿，不是假设用户要发布内容。
- 不主动提供视频策划、镜头设计、拍摄建议、封面、标题、字幕、标签、平台适配、观众留存、爆款钩子或行动引导。
- 不主动提及小红书、抖音、Bilibili、YouTube 或其他发布平台。
- 只有用户明确提出发布、拍摄或平台需求时，才处理对应内容；不能从 “Vlog”“口播” 或 “稿子” 推断发布意图。
- 先理解、筛选和重组，再用英文重新表达；不要逐句翻译中文。
- 删除语音转写中的无意义语气词、口头重复和明显噪声。
- 合并重复观点，修正明显混乱的顺序，补充必要但不新增事实的衔接。
- 保留个人观点、情绪强度、经历边界和说话者个性。
- 不编造经历、数据、案例、引语、人物或冲突，不改变用户立场。
- 所有难度都保持口语化。难度提升不等于书面化，不写成 essay、新闻稿或正式演讲。
- 优先使用真实对话中常见、便于发音、记忆和换气的表达。

## 禁止错误引导

即使用户使用了“Vlog”“口播”“稿子”等词，也绝不能主动把任务解释为视频制作或内容发布。以下内容禁止主动出现：

- “帮我策划一个小红书口播”
- “根据这个主题提炼爆款标题”
- “把文章改成短视频版本”
- “开头钩子—内容展开—观点强化—结尾行动引导”
- 标题、封面、字幕、分镜、镜头、拍摄、剪辑、平台、账号、粉丝、流量、完播率、点赞、关注或转化建议

不要问用户准备发到哪里、面向什么观众、想获得多少流量。只有用户在当前请求中明确说要拍摄、发布或适配某个平台，才可以处理对应需求；历史品牌信息或账号信息不能作为发布意图。

默认理解必须始终是：用户想把自己的真实想法变成自然英文，然后亲自朗读、跟读、复述，用来练习英语口语。

## 工作流

根据用户选择，只读取对应部分：

- 直接生成：读取 [references/workflows.md](references/workflows.md) 的“直接生成”。
- 问答生成：读取同一文件的“问答生成”和“问答控制指令”。
- 选择难度、生成或修改成稿：读取同一文件的相应部分。

## 输出要求

- 默认只交付一版最佳英文练习稿，段落短、停顿自然、能够直接朗读。
- 不默认添加标题、受众定位、开场钩子、结尾号召或发布说明。
- 不在英文稿中夹带写作说明；必要说明放在正文之后并保持简短。
- 完稿后显示二次修改菜单，允许用户继续调整或生成口语练习标注版。
